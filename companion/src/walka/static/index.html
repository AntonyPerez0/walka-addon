How to start a walk

  • In World of Warcraft: type /walka start or press Start on the Walka HUD. The belt then follows your character.
  • Any other game: start a manual session and set the speed yourself.

Getting started

  1. Connect the treadmill Switch the pad on and close the UREVO phone app - the pad accepts only one Bluetooth connection.
    Treadmill
  2. Install the game addon Copies Walka into World of Warcraft's AddOns folder. Then restart the game and tick Walka in the AddOns list.
  3. Let Walka see the game Run the game windowed or borderless with the top-left corner of its window visible. This ticks itself when the first signal arrives.
    Signal
  4. Enter your weight and height Calories depend on your weight; the step estimate on your height.
    Profile
