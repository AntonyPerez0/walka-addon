How to start a walk

  • In World of Warcraft: type /walka start or click the ▶ button on the Walka HUD. The belt then follows your character.
  • Any other game: start a manual session and set the speed yourself.

You use Walka at your own risk. It moves a motorised belt, it comes with no warranty, and it is not a safety device or a medical device. Keep the treadmill's remote within reach, and stop if you feel dizzy or unwell. Read the disclaimer

Getting started

  1. Connect the treadmill Done Switch the treadmill on and close its own phone app - most treadmills accept only one Bluetooth connection.
    Treadmill
  2. Install the game addon Done Copies Walka into World of Warcraft's AddOns folder. Then restart the game and tick Walka in the AddOns list.
  3. Let Walka see the game Done Run the game windowed or borderless with the top-left corner of its window visible. This ticks itself when the first signal arrives.
    Signal
  4. Enter your weight and height Done Calories depend on your weight; the step estimate on your height.
    Profile
